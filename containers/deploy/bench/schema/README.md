# Benchmark configuration reference

Generated by `bench/schemadoc` from `schema/experiment.json`, `schema/app.json` -- do not edit.
Regenerate with `./schemadoc --write`; `test_bench.sh` fails if this
file is stale.

A blank meaning is a key the schema does not describe yet; they are
tracked in `schema/undocumented.txt`.  Cross-field rules a schema
cannot state live in `benchlib/experiment.py` and are what
`bench validate` adds on top of what is below.

## Benchmark experiment

What to sweep: which images, which apps, which rank/thread decompositions, and how the cross product is split into jobs. Host-side only -- bench/submit expands this into a flat job.env per job, and the job itself never parses YAML.

## Application contract

What an application must declare so the runner can drive it without knowing which one it is. Installed into the image at /container/app.d/<app>/app.yaml by build_<app>.sh, beside the prepare/launch/extract hooks. An app with no hooks at all is legal: an app.yaml with just app and binary gets you wall time and a placement verdict, which is the ten-minute entry point that makes the contract adoptable.

### `app`

| key | type | required | constraints | meaning |
| --- | --- | --- | --- | --- |
| `app` | string | yes | matches `/^[a-z0-9][a-z0-9_-]*$/` | The name the runner is asked for. Must match the app.d directory. |
| `binary` | string |  |  | Absolute path inside the image. Required unless there is a launch hook, which may pick a different executable and add flags. |
| [`figures_of_merit`](#appfigures_of_merit) | object |  | no other keys | Ramble's noun, on purpose. Every key that extract may print, plus wall_s which the runner always provides. |
| `notes` | string |  |  | Free text for whoever reads a results directory a year from now: what the numbers mean, and what would make them not mean it. |
| `primary_fom` | string |  |  | Which figure of merit decides a comparison. Must name a key in figures_of_merit. Read host-side by bench/collect, from the app.yaml copied into the results directory. |
| [`requires`](#apprequires) | object |  | no other keys |  |
| [`success_criteria`](#appsuccess_criteria) | object |  | no other keys |  |
| `version` | string |  |  | Recorded in every result row. A @PLACEHOLDER@ is substituted by build_<app>.sh at install time. |
